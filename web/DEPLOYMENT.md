# Página informativa

O projeto Cloudflare Pages `biblioteca-pessoal` publica somente a página informativa em `web/index.html`. O login e a aplicação web Supabase deixaram de ser publicados. A página explica que o produto é local e aponta para o repositório; ainda não há instalador oficial.

O código React/Supabase em `web/src` foi preservado como protótipo arquivado e não é carregado pela página pública.

- GitHub: https://github.com/sistemasgratuitos2001/Sistemas-Gratuitos
- Página: https://biblioteca-pessoal-5tk.pages.dev

As próximas versões instaláveis serão preparadas a partir do mesmo repositório e distribuídas por GitHub Releases, mantendo a base de cada instalação separada do código.

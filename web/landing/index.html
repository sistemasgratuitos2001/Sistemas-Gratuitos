Biblioteca Pessoal

O seu acervo fica no seu computador.

A Biblioteca Pessoal está a ser preparada como um programa local para casas, escritórios e pequenas bibliotecas. Cada instalação mantém os seus próprios dados.

Experimente o beta online. Esta versão está em testes. Use apenas dados fictícios; não introduza informação pessoal nem dados reais de leitores. O instalador offline continua em preparação.
Experimentar a versão beta Ver o projeto no GitHub
O acesso por vários computadores poderá ser feito pela rede local da biblioteca, sem tornar os dados públicos na Internet.
